# Melhem — Поиск, сравнение и заказ лекарств в Туркменистане

## Бизнес-задача

Melhem решает полный цикл покупки лекарств: пользователь находит нужное лекарство, сравнивает цены между аптеками, оформляет заказ и получает его — доставкой или самовывозом.

**Целевая аудитория:** жители Туркменистана, которые ищут и покупают лекарства для себя и близких.

**Языки:** Туркменский (основной), Русский.

---

## Модель данных

```
Пользователь ──(создаёт)──▶ Заказ ──(содержит)──▶ Позиции заказа
     │                         │                        │
  Адреса доставки          Аптека                   Наличие (Inventory)
  Телефон                  Статус                   Количество
  История заказов          Способ получения         Цена на момент заказа
                           Сумма
                           Адрес доставки / точка самовывоза

Аптека ──(имеет много)──▶ Наличие ──(ссылается на)──▶ Лекарство
     │                        │                            │
  Зона доставки           Цена в аптеке               Категории (много)
  Мин. сумма заказа       Остаток                     Производитель
  Стоимость доставки                                  Страна происхождения
                                                      Диапазон цен (min–max)
                                                      Форма выпуска
                                                      Дозировка, состав, побочные эффекты
```

## Структура приложения

### Таб 1 — Главная (Esasy)

**Задача:** быстрый доступ к поиску + обзор каталога для ознакомительного сёрфинга.

#### Поиск (главный элемент)
- Поисковая строка — первое что видит пользователь
- Поиск по названию лекарства, активному веществу, торговому названию
- История последних 5 запросов (при пустом поле)
- Возможность очистить историю
- Результаты в реальном времени (debounce 300ms)

#### Баннеры/Акции
- Карусель промо-баннеров (ссылки на внешние ресурсы)
- Автопрокрутка, свайп, индикаторы-точки

#### Популярные категории
- 4–6 категорий с иконками
- Тап → список лекарств в категории

#### Ближайшие аптеки (новый раздел)
- На основе геолокации пользователя (если разрешил)
- Fallback: все аптеки, отсортированные по популярности
- Карточка: логотип, название, адрес, статус (открыта/закрыта)
- «Показать все» → полный список аптек

#### Страны-производители
- Горизонтальный скролл: флаг + название + кол-во лекарств
- Тап → лекарства из этой страны

#### Производители
- Горизонтальный скролл: логотип + название + кол-во лекарств
- Тап → лекарства этого производителя

---

### Таб 2 — Категории (Kategoriýalar)

**Задача:** структурированный поиск, когда пользователь не знает точного названия.

- Сетка категорий (2 колонки) с изображениями
- Каждая карточка: иконка, название, количество лекарств
- Тап → список лекарств с бесконечной прокруткой
- Возможность сортировки (по цене, по названию, по популярности)

---

### Таб 3 — Корзина (Sebet)

**Задача:** собрать лекарства из одной или нескольких аптек и оформить заказ.

#### Пустое состояние
- Иллюстрация корзины + текст «Корзина пуста»
- Кнопка «Перейти к поиску»

#### Корзина с товарами
- Товары **сгруппированы по аптекам** (каждая аптека — отдельная секция)
- Шапка секции: логотип аптеки, название, статус (открыта/закрыта)

#### Карточка товара в корзине
```
┌─────────────────────────────────────┐
│ [Фото]  Название лекарства      [✕] │
│          Форма — Доза                │
│          12.50 TMT                   │
│          [−]  2  [+]                 │
│                         Итого: 25.00 │
└─────────────────────────────────────┘
```
- Фото, название, форма выпуска
- Цена за единицу
- Счётчик количества (−/+), ограничен остатком на складе
- Итого за позицию
- Кнопка удаления

#### Итого по аптеке
- Подытог товаров
- Стоимость доставки (или «Бесплатно» / «Самовывоз — бесплатно»)
- Мин. сумма заказа — если не достигнута, показать сколько осталось
- Кнопка «Оформить заказ» для этой аптеки

#### Важные правила
- Один заказ = одна аптека (нельзя смешивать аптеки в одном заказе)
- Если товары из нескольких аптек — каждая оформляется отдельно
- При изменении количества — пересчёт итого в реальном времени
- Если товар закончился — показать предупреждение и предложить удалить
- Корзина хранится локально, сохраняется между сессиями

### Таб 4 — Избранное (Halanlarym)

**Задача:** быстрый доступ к лекарствам, которые пользователь покупает регулярно.

- Пустое состояние: иллюстрация + текст «Добавьте лекарства в избранное»
- Сетка избранных лекарств (идентична обычной сетке)
- Кнопка-закладка на каждой карточке лекарства во всём приложении
- Данные хранятся локально, сохраняются между сессиями
- Свайп для удаления из избранного (новый UX)
- Кнопка «В корзину» на каждой карточке — быстрое добавление

---

### Таб 5 — Профиль (Profil)

**Задача:** управление аккаунтом, заказами и персональными настройками.

#### Без авторизации
- Кнопка «Войти / Зарегистрироваться»
- Настройки языка и темы доступны без входа
- Юридические ссылки

#### С авторизацией
- **Имя пользователя** и телефон
- **Мои заказы** → экран истории заказов
- **Мои адреса** → управление адресами доставки
- **Язык** — переключение Turkmen / Русский
- **Тема** — Светлая / Тёмная / Системная
- **Уведомления** — настройка push-уведомлений
- **Политика конфиденциальности**
- **Условия использования**
- **Помощь / Обратная связь**
- **Выйти**
- **Версия приложения**

## Ключевые экраны

### Экран лекарства (Drug Detail)

**Задача:** полная информация о лекарстве + где купить дешевле.

#### Секция 1 — Визуал
- Карусель фотографий препарата (свайп, индикаторы)
- Кнопка «В избранное» поверх изображения

#### Секция 2 — Основная информация
- Название препарата
- Форма выпуска + дозировка (например: «Таблетка — 500 мг»)
- Категории (чипсы, кликабельные)
- Производитель + страна (кликабельно)

#### Секция 3 — Цена
- **Если из конкретной аптеки:** точная цена + название аптеки
- **Если из каталога:** диапазон «от X до Y TMT»
- **Если цена одна:** «X TMT»

#### Секция 4 — Где купить (ключевая фича)
- Список аптек где есть это лекарство, отсортированный по цене (от дешёвой к дорогой)
- Карточка: название аптеки, цена, статус (открыта/закрыта), расстояние (будущее)
- **Кнопка «В корзину»** на каждой строке — добавляет 1 шт. из выбранной аптеки
- Тап на название аптеки → экран аптеки

#### Секция 5 — Подробности (раскрывающиеся аккордеоны)
- Активное вещество
- Показания к применению
- Противопоказания
- Побочные эффекты
- Способ применения
- Состав

#### Секция 6 — Действия
- **Кнопка «В корзину»** (основная, sticky внизу экрана) — выбор аптеки + добавление
- Кнопка «Поделиться» — deep link на лекарство

---

### Экран аптеки (Pharmacy Detail)

**Задача:** вся информация об аптеке + её ассортимент.

#### Шапка
- Логотип аптеки
- Название
- Статус: «Открыта — работает до 22:00» (зелёный) / «Закрыта» (красный)
- Адрес

#### Быстрые действия (иконки)
- **Позвонить** — открывает звонилку (если есть номер)
- **Маршрут** — открывает Google/Apple Maps с координатами
- **Сайт** — открывает браузер (если есть)
- **Email** — открывает почтовый клиент (если есть)

#### График работы
- Таблица: день недели → часы работы
- Текущий день выделен

#### Лекарства в наличии
- Сетка первых 6 лекарств с ценами
- «Показать все» → полный список наличия (бесконечная прокрутка)
- Каждая карточка: фото, название, форма, цена в этой аптеке

---

### Экран результатов (Drugs List)

**Задача:** список лекарств с фильтрацией.

- Заголовок: название категории / страны / производителя
- Сетка лекарств (2 колонки, бесконечная прокрутка)
- Карточка лекарства: фото, название, форма выпуска, цена/диапазон, кнопка избранного
- Сортировка: по цене ↑↓, по названию, по наличию (будущее)
- Фильтры: форма выпуска, ценовой диапазон (будущее)

## Ecommerce: Заказы, доставка, самовывоз

### Авторизация

**Задача:** минимальный барьер входа. Авторизация нужна только для оформления заказа.

#### Вход по телефону (основной способ)
1. Пользователь вводит номер телефона (+993...)
2. Получает SMS с 4-значным кодом
3. Вводит код → авторизован
4. Если новый пользователь — автоматическая регистрация (имя можно добавить позже)

#### Когда требуется авторизация
- Оформление заказа → перенаправление на экран входа → после входа возврат к оформлению
- Просмотр истории заказов
- Управление адресами

#### Когда НЕ требуется
- Поиск, просмотр лекарств, аптек
- Избранное (хранится локально)
- Корзина (хранится локально)
- Настройки языка/темы

---

### Добавление в корзину

#### Из экрана лекарства (Drug Detail)
1. Пользователь нажимает «В корзину» (sticky кнопка внизу)
2. Если лекарство есть в одной аптеке → сразу добавляется
3. Если в нескольких аптеках → bottom sheet «Выберите аптеку»:
   ```
   ┌─────────────────────────────────────┐
   │  Выберите аптеку                    │
   │                                     │
   │  [Logo] Аптека Saglyk     12.50 TMT │
   │          Açyk · 1.2 km        [+]   │
   │                                     │
   │  [Logo] Аптека Melhem     13.00 TMT │
   │          Açyk · 2.5 km        [+]   │
   │                                     │
   │  [Logo] Аптека Derman     11.80 TMT │
   │          Ýapyk · 3.1 km       [+]   │
   └─────────────────────────────────────┘
   ```
4. Тап [+] → добавлено, показать toast «Добавлено в корзину»

#### Из секции «Где купить» (на экране лекарства)
- Кнопка [+] рядом с каждой аптекой → сразу добавляет 1 шт.

#### Из карточки лекарства (в списках)
- Долгий тап или кнопка корзины → аналогичный bottom sheet

#### Из экрана аптеки (Pharmacy Detail)
- На каждой карточке лекарства — кнопка [+] → добавляет из этой аптеки

#### Логика корзины
- Товар привязан к конкретной аптеке (Inventory ID)
- Если добавить тот же товар из другой аптеки — это отдельная позиция в другой секции
- Количество ограничено остатком (`inventory.stock`)
- При добавлении проверяется актуальность цены и наличия (запрос к API)

### Оформление заказа (Checkout)

#### Шаг 1 — Проверка корзины
- Показать список товаров из выбранной аптеки
- Пересчёт цен (если изменились с момента добавления — показать предупреждение)
- Проверка наличия (если товар закончился — предложить удалить)
- Итого: подытог + доставка

#### Шаг 2 — Способ получения
```
┌─────────────────────────────────────┐
│  Как вы хотите получить заказ?      │
│                                     │
│  ┌───────────────┐ ┌──────────────┐ │
│  │  🚗 Доставка  │ │ 🏪 Самовывоз │ │
│  │  30-60 мин    │ │  Бесплатно   │ │
│  │  5.00 TMT     │ │              │ │
│  └───────────────┘ └──────────────┘ │
└─────────────────────────────────────┘
```

**Доставка:**
- Выбор адреса из сохранённых или ввод нового
- Адрес: улица, дом, квартира, подъезд, этаж, комментарий курьеру
- Проверка: входит ли адрес в зону доставки аптеки
- Если не входит → сообщение «Аптека не доставляет по этому адресу» + предложить самовывоз
- Ориентировочное время доставки
- Стоимость доставки (зависит от аптеки, может быть бесплатной от определённой суммы)

**Самовывоз:**
- Адрес аптеки + карта
- Время готовности заказа (ориентировочное)
- График работы аптеки
- Бесплатно

#### Шаг 3 — Контактные данные
- Телефон (предзаполнен из профиля)
- Имя получателя (предзаполнено)
- Возможность заказать для другого человека (другой телефон/имя)

#### Шаг 4 — Оплата
- **Наличные при получении** (основной способ для Туркменистана)
- **Банковский перевод** (будущее)
- **Онлайн-оплата** (будущее, когда появятся платёжные шлюзы)

#### Шаг 5 — Подтверждение
```
┌─────────────────────────────────────┐
│  Ваш заказ                          │
│                                     │
│  Аптека: Saglyk                     │
│  Способ: Доставка                   │
│  Адрес: ул. Махтумкули, 15, кв. 3  │
│  Время: ~45 мин                     │
│                                     │
│  Парацетамол 500мг × 2    25.00 TMT │
│  Ибупрофен 200мг × 1      18.50 TMT │
│  ─────────────────────────────────  │
│  Товары:                   43.50 TMT │
│  Доставка:                  5.00 TMT │
│  ─────────────────────────────────  │
│  Итого:                    48.50 TMT │
│                                     │
│  Оплата: Наличными                  │
│                                     │
│  [ Подтвердить заказ ]              │
└─────────────────────────────────────┘
```

#### После подтверждения
- Заказ отправляется на сервер
- Экран «Заказ оформлен» с номером заказа
- Автоматический переход на экран отслеживания
- Push-уведомление при смене статуса

### Статусы заказа

```
Оформлен → Принят аптекой → Собирается → Готов → В пути → Доставлен
                                           │
                                           └→ Готов к выдаче (самовывоз)
```

| Статус | Описание | Действия пользователя |
|--------|----------|----------------------|
| **Оформлен** (pending) | Заказ создан, ожидает подтверждения аптеки | Отменить заказ |
| **Принят** (accepted) | Аптека подтвердила заказ | Отменить заказ |
| **Собирается** (preparing) | Аптека собирает заказ | Связаться с аптекой |
| **Готов к выдаче** (ready_pickup) | Самовывоз: можно забирать | Показать QR-код |
| **В пути** (delivering) | Курьер едет к пользователю | Связаться с курьером |
| **Доставлен** (delivered) | Заказ получен | Оценить, повторить заказ |
| **Отменён** (cancelled) | Отменён пользователем или аптекой | — |
| **Отклонён** (rejected) | Аптека не может выполнить | Предложить альтернативу |

#### Причины отклонения аптекой
- Лекарство закончилось после оформления
- Аптека закрыта / не работает
- Адрес вне зоны доставки

При отклонении → push-уведомление + предложение оформить в другой аптеке.

- Один адрес «по умолчанию»
- Редактирование / удаление
- Максимум 5 адресов

#### Форма адреса
- Улица и дом (обязательно)
- Квартира / офис
- Подъезд
- Этаж
- Комментарий курьеру (например: «Звонить в домофон 15»)
- Метка (Дом / Работа / Другое)

│                   │

- Кнопка избранного (♡ / ♥)

- Форма выпуска + дозировка
- Цена или диапазон цен

- Если из общего каталога (без привязки к аптеке) — кнопка [+] открывает выбор аптеки

## Логика работы

### Ценообразование
1. Каждая аптека устанавливает свою цену через систему «Наличие» (Inventory)
2. У лекарства `priceRange = {min, max}` — рассчитывается по всем аптекам
3. При просмотре из конкретной аптеки — показывается её цена
4. Раздел «Где купить дешевле» — все аптеки отсортированы по цене

### Статус аптеки
1. У каждой аптеки — график работы по дням недели: `{open: "08:00", close: "22:00"}`
2. Проверка в реальном времени: текущий день + текущее время → открыта/закрыта
3. Отображается как бейдж на карточке аптеки

### Избранное
1. Хранится локально на устройстве (массив ID лекарств)
2. Синхронизация между сессиями через персистентное хранилище
3. Переключается одной кнопкой из любого места приложения

### Поиск
1. Полнотекстовый поиск по названию лекарства
2. История последних 5 просмотренных лекарств из поиска
3. Очистка истории одной кнопкой

### Корзина
1. Хранится локально на устройстве (массив позиций)
2. Позиция = `{inventoryId, drugId, pharmacyId, quantity, priceAtAdd}`
3. Группировка по аптекам при отображении
4. При открытии корзины — фоновая валидация: цены и остатки актуальны?
5. Если цена изменилась — показать старую (зачёркнутую) и новую
6. Если товар закончился — пометить серым + предложить удалить
7. Максимум 20 позиций в корзине (ограничение UX)

### Оформление заказа
1. Авторизация обязательна (если не авторизован — перенаправление на вход)
2. Один заказ = одна аптека
3. Проверка минимальной суммы заказа перед отправкой
4. Проверка зоны доставки по адресу пользователя
5. Фиксация цен на момент создания заказа (не корзины)
6. После успешного оформления — позиции удаляются из корзины
7. Заказ создаётся со статусом `pending`

### Доставка
1. Аптека определяет: зону, стоимость, мин. сумму, время
2. Бесплатная доставка от определённой суммы (настраивается аптекой)
3. Если адрес вне зоны — доставка недоступна, предложить самовывоз
4. Ориентировочное время — не гарантия, показывается как диапазон (30–60 мин)

### Самовывоз
1. Всегда бесплатный
2. Адрес аптеки + кнопка «Маршрут» (Google/Apple Maps)
3. Время готовности — ориентировочное (обычно 15–30 мин)
4. Забирать можно только в часы работы аптеки
5. Заказ хранится в аптеке 24 часа, потом отменяется автоматически

### Повторный заказ
1. Из истории заказов — кнопка «Повторить»
2. Проверка: все ли товары ещё в наличии и по какой цене
3. Если что-то изменилось — показать diff и подтвердить
4. Добавляет в корзину (не оформляет сразу)

### Локализация
1. Весь контент (лекарства, категории, аптеки) имеет переводы на tm и ru
2. UI-элементы переведены через i18n
3. Язык переключается мгновенно без перезагрузки

#### Новые эндпоинты (ecommerce)

**Авторизация:**
- `POST /auth/send-code` — отправить SMS-код на номер
- `POST /auth/verify-code` — подтвердить код, получить токен
- `POST /auth/refresh` — обновить токен
- `GET /auth/me` — текущий пользователь
- `PUT /auth/me` — обновить профиль (имя)

**Корзина (валидация):**
- `POST /cart/validate` — проверить актуальность цен и наличия для списка `{inventoryId, quantity}[]`

**Заказы:**
- `POST /orders` — создать заказ
- `GET /orders` — список заказов пользователя (с пагинацией)
- `GET /orders/:id` — детали заказа со статусом
- `PUT /orders/:id/cancel` — отменить заказ
- `POST /orders/:id/repeat` — получить данные для повторного заказа (проверка наличия)

**Адреса:**
- `GET /addresses` — список адресов пользователя
- `POST /addresses` — добавить адрес
- `PUT /addresses/:id` — обновить адрес
- `DELETE /addresses/:id` — удалить адрес

**Доставка:**
- `POST /delivery/check` — проверить доступность доставки `{pharmacyId, addressId}` → зона, цена, время

**Уведомления:**
- `POST /devices` — зарегистрировать push-токен устройства
- `GET /notifications` — список уведомлений пользователя
